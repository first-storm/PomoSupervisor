番茄计时器 · Apple Icon Composer SVG 素材

画布为 1024 × 1024，适用于 iPhone、iPad 和 Mac。
将四个 SVG 导入同一个项目。侧栏从底到顶依次为 Tomato、Dial、Leaf、Timer。
四层共用同一画布坐标。若导入后软件自动调整图层位置或比例，以画布中心和原始比例对齐。
浅色背景可在 Icon Composer 中设为 #FCE8E5。
可为 Tomato、Dial 和 Leaf 使用系统 Liquid Glass 效果，Timer 保持清晰的实色，关闭该层 Effects。
在 Icon Composer 中预览 Default、Dark、Clear 和 Tinted，然后保存 .icon 项目。
